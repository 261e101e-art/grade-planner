# Grade Planner

[![Tests](https://github.com/261e101e-art/grade-planner/actions/workflows/test.yml/badge.svg)](https://github.com/261e101e-art/grade-planner/actions/workflows/test.yml)

Grade Planner is a command-line tool for calculating weighted course grades and estimating the score required to reach a target final grade.

It is useful when a course grade is composed of multiple components such as midterm exams, assignments, and final exams.

## Features

- Read course grade information from a CSV file
- Calculate the current weighted score
- Calculate the score required to reach a target final grade
- Detect unreachable target grades
- Generate a grade projection graph
- Export the graph as a PDF file
- Validate input data
